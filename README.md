# 🐺 WolfPack

> A modular command-line toolkit built in Modern C++.

## Overview

WolfPack is a long-term C++ project designed to learn software engineering by building real software instead of isolated exercises.

The project starts as a simple command-line application and gradually evolves into a collection of useful utilities.

Each new feature introduces a new programming concept while improving the project's architecture and code quality.

---

- Learn Modern C++
- Practice Git & GitHub
- Build a professional portfolio
- Write clean and maintainable code
- Improve problem-solving skills
